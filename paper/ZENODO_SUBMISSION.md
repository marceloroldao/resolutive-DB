## Description

BDR v0.1.0 is a reproducible Research Preview of an experimental persistent key-value database architecture investigating deterministic resolutive addressing, local partitioning, adaptive structures, segmented write-ahead logging, atomic checkpoints, crash recovery, and durability-parity benchmarking against SQLite. The release does not claim production readiness or strict worst-case O(1) complexity for the complete engine.
