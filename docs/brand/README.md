# Resolutive-DB — Identidade Visual

Versão inicial da identidade visual oficial do Banco de Dados Resolutivo (BDR).

## Conceito

O BDR não é representado pelo cilindro convencional de banco de dados. A marca parte da própria ontologia resolutiva: um **núcleo informacional** só adquire sentido dentro de um campo de **relações, órbitas, direção e profundidade**.

O símbolo combina:

- **núcleo** — unidade de informação / nódulo;
- **órbitas cruzadas** — relações simultâneas em planos diferentes;
- **nódulo orbital secundário** — informação contextual relacionada;
- **assimetria controlada** — direção, trajetória e resolução;
- **profundidade** — preparação para a linguagem espacial do BDR Explorer e da Memoria.ia.

## Princípio de marca

> Informação existe pelas relações.

A identidade visual deve comunicar estrutura, resolução e movimento sem sugerir que o BDR é apenas um armazenamento tabular ou relacional tradicional.

## Tipografia

- Interface e marca: **Inter** (fallback: Segoe UI / Arial).
- Dados, IDs, endereços e métricas: **JetBrains Mono** (fallback: Consolas / monospace).

Fontes não são versionadas neste diretório; o projeto apenas declara as famílias recomendadas.

## Linguagem visual resolutiva

A linguagem do Explorer pode derivar diretamente da marca, porém marca e visualização devem continuar separadas:

- nódulos = unidades informacionais;
- linhas/arcos = relações;
- órbitas = contexto dinâmico;
- camadas = níveis de abstração;
- eixo/profundidade = relações que não pertencem ao mesmo plano 2D;
- movimento = exploração/descoberta;
- resolução = convergência relacional.

## Regras de uso

1. Não deformar o símbolo.
2. Não substituir a paleta principal por cores arbitrárias em material oficial.
3. Não remover o núcleo central do símbolo.
4. Não reduzir a marca a um ícone genérico de banco de dados.
5. Em UI muito pequena, utilizar apenas `logo-symbol.svg`.
6. Em fundos claros, utilizar uma futura variante light dedicada ou a versão monocromática apropriada.
