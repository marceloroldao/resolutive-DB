## Python benchmark observation

The installed-wheel benchmark is evidence of successful operation, not evidence that BDR is universally faster than SQLite. On the V100 runner, SQLite Python was faster in the tested write workloads.

Observed PUT throughput:

| Configuration | BDR wheel | SQLite Python |
|---|---:|---:|
| batch = 1 | 3,975.87 ops/s | 9,151.63 ops/s |
| batch = 128 | 83,802.72 ops/s | 267,822.64 ops/s |

Observed GET throughput:

| Configuration | BDR wheel | SQLite Python |
|---|---:|---:|
| batch = 1 dataset | 96,762.79 ops/s | 125,806.69 ops/s |
| batch = 128 dataset | 100,675.11 ops/s | 124,564.80 ops/s |

These results must be preserved as part of the research record. A release must not claim general performance superiority over SQLite, LMDB, LevelDB, or RocksDB unless a directly comparable benchmark supports that claim.
